# 智慧体育系统 - 简易状态持久化方案（Vue3 + sessionStorage）

## 一、方案目标

当前项目只需要实现：

* 页面增删改查
* 页面数据交互
* 页面刷新后数据不丢失
* 重启前端后数据自动清空

因此：

```txt
不需要 Pinia
不需要 Vuex
不需要 localStorage
```

直接使用：

```txt
Vue3 + composables + sessionStorage
```

即可满足需求。

---

## 二、为什么使用 sessionStorage

`sessionStorage` 生命周期：

| 操作       | 数据是否保留 |
| -------- | ------ |
| 页面刷新（F5） | ✅ 保留   |
| 页面跳转     | ✅ 保留   |
| 关闭浏览器标签页 | ❌ 清空   |
| 重启前端项目   | ❌ 清空   |

这与当前项目需求完全一致。

---

## 三、核心思路

```
MOCK 数据用 ref 包一层，页面内直接增删改查。
需要刷新保命就加 sessionStorage。
重启前后端？sessionStorage 自动清空，数据自然重置。
```

**各页面内写死的 mock 数据 → 逐个改用 usePersistedRef**

## 五、通用封装（只有一个文件）

### usePersistedRef.js

```js
// src/composables/usePersistedRef.js

import { ref, watch } from 'vue'

/**
 * 带 sessionStorage 持久化的 ref
 * @param {string} key - sessionStorage 键名
 * @param {*} defaultValue - 默认值（通常是 MOCK 数据）
 * @returns {Ref} 响应式引用，自动同步到 sessionStorage
 */
export function usePersistedRef(key, defaultValue) {
  // 先从 sessionStorage 恢复，没有就用默认值
  let initialValue = defaultValue
  try {
    const saved = sessionStorage.getItem(key)
    if (saved !== null) {
      initialValue = JSON.parse(saved)
    }
  } catch (e) {
    // 解析失败，使用默认值
    console.warn(`sessionStorage key "${key}" 解析失败，使用默认值`)
  }

  const data = ref(initialValue)

  // 自动同步到 sessionStorage
  watch(
    data,
    (newValue) => {
      sessionStorage.setItem(key, JSON.stringify(newValue))
    },
    { deep: true }
  )

  return data
}
```

## 七、页面使用方式

### 7.1 学生管理页面

```vue
<!-- StudentManagement.vue -->
<script setup>
import { ref, computed } from 'vue'
import { usePersistedRef } from '@/composables/usePersistedRef'
import { MOCK_STUDENTS, MOCK_SCHOOLS } from '@/data/mock'

// ========== 持久化数据（刷新保命）==========
const students = usePersistedRef('smart_pe_students', [...MOCK_STUDENTS])

// ========== 当前学校 ==========
const currentSchool = ref('school1')

// ========== 搜索 ==========
const keyword = ref('')

// ========== 计算属性 ==========
const filteredStudents = computed(() => {
  let list = students.value.filter(s => s.schoolId === currentSchool.value)
  if (keyword.value) {
    list = list.filter(s => s.name.includes(keyword.value))
  }
  return list
})

// ========== 增删改查 ==========
const addStudent = () => {
  students.value.push({
    id: Date.now(),
    schoolId: currentSchool.value,
    name: '新学生',
    gender: '男',
    age: 15,
    score: 0
  })
}

const removeStudent = (id) => {
  students.value = students.value.filter(s => s.id !== id)
}

const updateStudent = (id, data) => {
  const target = students.value.find(s => s.id === id)
  if (target) Object.assign(target, data)
}
</script>

<template>
  <div>
    <!-- 学校切换 -->
    <select v-model="currentSchool">
      <option v-for="s in MOCK_SCHOOLS" :key="s.id" :value="s.id">{{ s.name }}</option>
    </select>

    <!-- 搜索 -->
    <input v-model="keyword" placeholder="搜索姓名..." />

    <!-- 表格 -->
    <table border="1">
      <tr>
        <th>姓名</th>
        <th>性别</th>
        <th>年龄</th>
        <th>成绩</th>
        <th>操作</th>
      </tr>
      <tr v-for="s in filteredStudents" :key="s.id">
        <td>{{ s.name }}</td>
        <td>{{ s.gender }}</td>
        <td>{{ s.age }}</td>
        <td><input v-model.number="s.score" @change="updateStudent(s.id, { score: s.score })" /></td>
        <td>
          <button @click="updateStudent(s.id, { name: s.name + '(已修改)' })">修改</button>
          <button @click="removeStudent(s.id)">删除</button>
        </td>
      </tr>
    </table>

    <button @click="addStudent">新增学生</button>
  </div>
</template>
```

## 九、核心原则

### 1. 数据交互要求
- **新增：** 直接 `push` 到 ref，自动持久化
- **修改：** 直接修改 ref 属性，自动持久化
- **删除：** `filter` 过滤 ref，自动持久化
- **搜索：** 用 `computed` 过滤，不持久化搜索词（可选）

### 2. 持久化行为
- **页面刷新（F5）：** 自动从 sessionStorage 恢复
- **页面跳转：** 数据保持不变
- **关闭标签页：** sessionStorage 清空，下次打开恢复 MOCK
- **多标签页隔离：** 每个标签页独立

### 3. 页面内代码结构

```js
// 1. 导入
import { usePersistedRef } from '@/composables/usePersistedRef'
import { MOCK_XXX } from '@/data/mock'

// 2. 持久化数据（核心：这一行替代原来的 ref）
const data = usePersistedRef('smart_pe_key', [...MOCK_XXX])

// 3. 本地状态（不持久化）
const keyword = ref('')
const formVisible = ref(false)

// 4. 计算属性
const filtered = computed(() => { /* 过滤逻辑 */ })

// 5. 增删改查（直接操作 ref）
const add = () => data.value.push({...})
const remove = (id) => data.value = data.value.filter(...)
const update = (id, val) => { const item = data.value.find(...); item.xxx = val }
```

## 十、注意事项

### 1. 不要存函数

sessionStorage 只能存 JSON：

```js
// ❌ 错误
{ fn: () => {} }

// ✅ 正确
{ name: '张三', age: 15 }
```

### 2. 不要存超大数据

sessionStorage 容量约 5-10MB，适合：
- 表单数据
- 列表数据（几百条）
- 页面配置

不适合：
- 图片、视频
- 上万条数据

### 3. 不要用 localStorage

```txt
localStorage    → 永久保存，重启还在 ❌
sessionStorage  → 关闭标签页清空，重启重置 ✅
```

### 4. MOCK 数据用展开符

```js
// ✅ 正确：复制一份，不污染原始 MOCK
const data = usePersistedRef('key', [...MOCK_STUDENTS])

// ❌ 错误：直接引用，可能污染原始数据
const data = usePersistedRef('key', MOCK_STUDENTS)
```

## 十一、最终结论

当前项目最适合的方案：

```txt
Vue3
+ 一个 usePersistedRef.js
+ 一个 mock.js

```

优点：

* 只有一个通用封装文件

* 页面内代码极简
* 不需要 Pinia
* 刷新不丢数据
* 重启自动重置
* 非常适合当前阶段
