> **版本**：v1.2  
> **更新日期**：2026-08-07

## 一、接口概览

| 接口类别 | 接口数量 | 调用方 | 说明 |

## 二、通用规范

### 2.1 推送接口认证方式（Header 签名）

所有**推送接收接口**必须在请求头中携带签名信息：

| Header 字段 | 类型 | 必填 | 说明 |
|------------|------|------|------|
| `timestamp` | number | 是 | 当前时间戳（毫秒，13位） |
| `sign` | string | 是 | MD5(check_string + timestamp)，32位小写 |

**签名算法：**
```javascript
sign = MD5(check_string + timestamp).toLowerCase()
```

**示例：**
```
check_string = "hailin_sport_check_2026"
timestamp    = "1784699567574"
sign         = MD5("hailin_sport_check_20261784699567574")
             = "a1b2c3d4e5f6..."  // 32位小写hex
```

**时间戳校验：** 服务端允许 ±5 分钟的时间偏差，超过则返回 `时间戳过期`。

### 2.2 响应格式

所有接口统一返回以下格式：

```javascript
{
  code: 0,           // 状态码：0=成功，-1=失败
  message: "success", // 提示信息
  data: {}           // 业务数据（查询接口有，推送接口无）
}
```

### 2.3 状态码说明

| code | 含义 | 场景 |
|------|------|------|
| `0` | 成功 | 请求处理成功 |
| `-1` | 参数错误/业务失败 | 签名错误、时间戳过期、缺少必填字段等 |

## 三、推送接收接口（大沩设备调用）

### 3.1 运动数据推送

接收大沩设备推送的运动成绩数据。

| 项目 | 值 |
|------|-----|
| **接口地址** | `POST /api/sports/push` |
| **Content-Type** | `application/json` |
| **调用方** | 大沩设备端（AI运动吧/体测吧/操场吧） |

**请求头：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `timestamp` | number | 是 | 时间戳（毫秒） |
| `sign` | string | 是 | MD5(check_string + timestamp) |

**请求体（Body）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `version` | string | 是 | 协议版本，固定 `v1.1` |
| `school_id` | string | 是 | 学校ID |
| `product_type` | number | 是 | 产品类型：`1`=AI运动吧，`2`=AI体测吧，`3`=AI操场吧 |
| `sport_type` | number | 是 | 运动类型（见下方枚举） |
| `mode` | number | 是 | 运动模式：`1`=练习模式，`2`=测试模式 |
| `sport_result` | array | 是 | 运动结果数组 |

**sport_result 数组元素：**

| 字段 | 类型 | 必填 | 适用运动 | 说明 |
|------|------|------|---------|------|
| `person_id` | string | 否 | 全部 | 人员ID，未识别时为空字符串 |
| `start_time` | number | 否 | 全部 | 运动开始时间（13位时间戳，毫秒） |
| `all_time` | number | 否 | 计时类 | 运动总时长（秒） |
| `score` | number | 否 | 全部 | 运动成绩（单位因运动类型而异） |
| `interrupt_count` | number | 否 | 跳绳 | 中断个数 |
| `jump_speed` | number | 否 | 跳远 | 平均速度（m/s） |
| `jump_height` | number | 否 | 跳远 | 腾空高度（cm） |
| `jump_angle` | number | 否 | 跳远 | 起跳角度 |
| `arm_angle` | number | 否 | 跳远 | 摆臂振幅 |
| `sub_count_list` | array | 否 | 跳绳/开合跳/仰卧起坐 | 分段计数，格式：`[{sub_time, sub_count}]` |
| `reaction_time` | number | 否 | 跑步类 | 反应时间（ms） |
| `weight` | number | 否 | BMI | 体重（kg） |
| `height` | number | 否 | BMI | 身高（cm） |
| `video_file_id` | string | 否 | 全部 | 关联视频文件ID |
| `face_file_id` | string | 否 | 全部 | 关联人脸抓拍文件ID |

**请求示例：**
```http
POST /api/sports/push
Content-Type: application/json
timestamp: 1784699567574
sign: a1b2c3d4e5f6...

{
  "version": "v1.1",
  "school_id": "9e3bfcd0-4b7e-11f1-866e-1deb8b635fb2",
  "product_type": 1,
  "sport_type": 1,
  "mode": 1,
  "sport_result": [
    {
      "person_id": "S_903146",
      "start_time": 1784699567574,
      "all_time": 60,
      "score": 150,
      "interrupt_count": 2,
      "sub_count_list": [
        { "sub_time": 10, "sub_count": 25 },
        { "sub_time": 20, "sub_count": 50 }
      ],
      "video_file_id": "vid_20260723_001",
      "face_file_id": "face_20260723_001"
    }
  ]
}
```

**响应示例：**
```json
{
  "code": 0,
  "message": "success"
}
```

### 3.2 文件上传推送

接收大沩设备推送的视频（mp4）或人脸抓拍（jpg）文件。

| 项目 | 值 |
|------|-----|
| **接口地址** | `POST /api/sports/files/push` |
| **Content-Type** | `multipart/form-data` |
| **调用方** | 大沩设备端 |

**请求头：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `timestamp` | number | 是 | 时间戳（毫秒） |
| `sign` | string | 是 | MD5(check_string + timestamp) |

**请求体（Form-Data）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `version` | string | 是 | 协议版本，如 `v1.0` |
| `file_id` | string | 是 | 文件唯一标识 |
| `file` | file | 是 | 文件内容 |
| `file_type` | number | 是 | 文件类型：`1`=jpg，`2`=mp4 |

**响应示例：**
```json
{
  "code": 0,
  "message": "success"
}
```

**限制说明：**
- 单文件最大：`50MB`
- 允许类型：仅 `jpg`、`mp4`

## 七、签名验证对照表

| 维度 | 调用大沩API（人员注册） | 接收大沩推送（运动数据） |
|------|----------------------|----------------------|
| 方向 | 我方 → 大沩 | 大沩 → 我方 |
| 密钥 | access_key_id + access_key_secret | check_string |
| 签名算法 | MD5(access_key_id + timestamp + access_key_secret) | MD5(check_string + timestamp) |
| 签名位置 | Body 中的 sign 字段 | Header 中的 sign 字段 |
| 时间戳位置 | Body 中的 timestamp 字段 | Header 中的 timestamp 字段 |
| Token | 需要 JWT Token | 不需要 Token |
