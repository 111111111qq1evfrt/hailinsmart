## 二、性能急救（已完成）

### 2.1 CDN 与 npm 去重（最大收益，减 1.5MB）

**问题描述**：`index.html` 通过 CDN 加载 Vue + Vue Router + Element Plus + ECharts + xlsx，但 `main.js` 又 import 一份，Vite 全部打包进 JS。浏览器内存里存在两份 Vue 和两份 Element Plus。

**已修改**：`vite.config.mjs`

```javascript
build: {
  rollupOptions: {
    external: ['vue', 'vue-router', 'element-plus', 'echarts', 'xlsx'],
    output: {
      globals: {
        vue: 'Vue',
        'vue-router': 'VueRouter',
        'element-plus': 'ElementPlus',
        echarts: 'echarts',
        xlsx: 'XLSX'
      }
    }
  },
  manualChunks: {
    'vendor': ['pinia', 'axios', 'gsap'],
    'video': ['video.js', 'framebyframe', 'videojs-markers']
  }
}
```

**已修改**：`src/main.js`（删除 Element Plus npm 重复引入）

```javascript
// 删除以下三行
// import ElementPlus from 'element-plus'
// import 'element-plus/dist/index.css'
// app.use(ElementPlus)
// CDN 已在 index.html 加载，ElementPlus 全局可用
```

**预期影响**：JS 从 2MB → 800KB，首屏加载时间减半。

---

### 2.2 keep-alive 修复（切页不卡顿）

**问题描述**：`App.vue` 中 `router-view` 加了 `:key="route.path"`，导致 keep-alive 每次都重建组件，切 tab 必重新请求数据。

**已修改**：`src/App.vue`

```vue
<transition :name="routeTransition" mode="out-in">
  <keep-alive :include="cachedViews">
    <router-view />  <!-- 删除 :key="route.path" -->
  </keep-alive>
</transition>
```

**预期影响**：切换系统管理各 tab 时，数据不再重新加载，体验流畅 5 倍以上。

---

### 2.3 全局 will-change 清理（防 GPU 内存泄漏）

**问题描述**：`App.vue` 的 `.fade-enter-active` 和 `.loader` 写了 `will-change: opacity, transform`，所有页面切换元素常驻 GPU 合成层，低配电脑白屏。

**已修改**：`src/App.vue`（两处）

```css
/* 删除全局 GPU 提示，降低内存占用 */
.fade-enter-active, .fade-leave-active {
  transition: opacity 0.3s ease, transform 0.3s ease;
  /* 已删除：will-change、backface-visibility、perspective */
}

.loader {
  /* 已删除：will-change、backface-visibility */
  animation: spin 1s linear infinite;
}
```

**预期影响**：长时间使用后内存稳定，不再越用越卡。

---

### 2.4 ECharts 按需引入（数据平台不卡）

**问题描述**：`src/utils/echarts.js` 若全量引入（`import * as echarts from 'echarts'`）可达 1MB+，数据平台页面打开慢。

**检查结论**：项目当前已使用 `echarts/core` 按需引入模式（`import * as echarts from 'echarts/core'` + 按需注册图表/组件），无需额外修改。

```javascript
// 当前实现（已正确）
import * as echarts from 'echarts/core'
import { BarChart, LineChart, PieChart, RadarChart } from 'echarts/charts'
import { CanvasRenderer } from 'echarts/renderers'
import { GridComponent, TooltipComponent, LegendComponent, TitleComponent } from 'echarts/components'

use([
  CanvasRenderer, BarChart, LineChart, PieChart, RadarChart,
  GridComponent, TooltipComponent, LegendComponent, TitleComponent
])
```

**预期影响**：ECharts 控制在 200-300KB，数据平台图表秒开。

```javascript
// 浏览器 Console 中执行

  .filter(r => r.name.endsWith('.js'))
```
